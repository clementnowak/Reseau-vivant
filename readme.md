
# Réseau vivant 🌿

Un site interactif et pédagogique pour découvrir les réseaux alimentaires et comprendre l'importance de la biodiversité.

## Objectif

Permettre aux enfants, adolescents et curieux de la nature de comprendre les relations entre les espèces animales et végétales.

## Fonctionnalités

- Exploration interactive des relations alimentaires
- Fiches pédagogiques sur les espèces
- Recherche d'animaux
- Mini-quiz éducatif

## Technologies

- HTML : structure
- CSS : apparence
- JavaScript : interactions et données
- GitHub : gestion des versions
- Netlify : hébergement

## Découvrir le site

https://reseau-vivant-education.netlify.app
