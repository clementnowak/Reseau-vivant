# Crédits des silhouettes

Les silhouettes d’animaux viennent de [PhyloPic](https://www.phylopic.org/), une bibliothèque d’illustrations libres. Seules les images publiées sous licence **CC0 (domaine public)** ou **Public Domain Mark** ont été retenues : aucune attribution n’est exigée, mais on cite quand même les auteurs.

Les fichiers sont simplifiés (tracés allégés, un seul remplissage, aucun script) par les outils de `tools/silhouettes/`. Quand la silhouette montre un proche cousin de l’espèce (même genre ou même famille), la colonne « Animal dessiné » l’indique.
